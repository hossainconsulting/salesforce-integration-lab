# Salesforce Integration Lab

## Purpose

Explore how Salesforce exchanges data with external applications.

This is a self-directed learning project, not client delivery.

## Current status

Planning only. This repository currently contains documentation.
No exercises, runnable implementation, tests or demonstrations have been added.

## Planned exercises

These are proposed activities, not completed capabilities.

- [ ] Authenticate to a development org without committing credentials.
- [ ] Read and write sample records through APIs.
- [ ] Handle validation errors, pagination and retry scenarios.
- [ ] Document field mappings and integration decisions.

There is no runnable implementation yet. Setup instructions and dependencies

## Evidence
